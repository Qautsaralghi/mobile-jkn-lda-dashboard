Analisis Topik Ulasan Mobile JKN Menggunakan LDA & Streamlit Dashboard

Repositori resmi untuk Capstone Project Kelompok 7 TOPSUS (Kelas 7B). Proyek ini melakukan scraping, preprocessing, pemodelan topik ulasan pengguna aplikasi Mobile JKN (versi 4.18.0) di Google Play Store, serta visualisasi eksploratif berbasis Streamlit.

Apakah Proyek Repositori Ini Perlu Coding?

Ya, perlu coding (Python)! Namun struktur programnya sudah terbagi menjadi beberapa modul utama secara modular:

  • Scraping Data: Menggunakan library google-play-scraper untuk mengambil ulasan terbaru versi 4.18.0.
  • Data Preprocessing: Menggunakan NLTK & Sastrawi untuk Cleansing, Lowercasing, Stopwords removal, dan Stemming Bahasa Indonesia.
  • Pemodelan LDA: Menggunakan Gensim untuk ekstraksi topik dan kalkulasi Coherence Score ($C_v$).
  • Dashboard Interaktif: Menggunakan Streamlit dan pyLDAvis untuk menyajikan hasil analisis kepada pengguna.

Langkah Membangun Repositori GitHub

Panduan praktis mengunggah dan mengelola repositori proyek kelompok di GitHub

1 Buat Repositori Baru di GitHub

Buka GitHub.com → Klik tombol "New Repository" → Beri nama mobile-jkn-lda-dashboard → Pilih Public → Centang Add a README file.

2 Clone Repositori ke Komputer Lokal
git clone https://github.com/username-anda/mobile-jkn-lda-dashboard.git
cd mobile-jkn-lda-dashboard
3 Buat File requirements.txt

Daftar pustaka Python yang dibutuhkan oleh proyek ini:

streamlit
gensim
nltk
Sastrawi
pandas
matplotlib
pyLDAvis
google-play-scraper
4 Commit & Push Kode ke GitHub
git add .
git commit -m "feat: Add LDA model and Streamlit dashboard codebase"
git push origin main
